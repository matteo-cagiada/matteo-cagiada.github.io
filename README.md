# matteo-cagiada.github.io

Personal homepage, served at https://matteo-cagiada.github.io/.
Project pages (e.g. `/mmcif-tools/`) keep working under this domain.

Edit the `CONFIG` block near the top of `index.html` (ORCID, Scholar, LinkedIn, email).
To show a CV link later, add `cv.pdf` next to `index.html` and set `cv: "cv.pdf"` in `CONFIG`.
